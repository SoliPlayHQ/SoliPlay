# SoliPlay
AI 导演驱动、AI 角色参与演绎的互动叙事引擎。

### 关于本项目的仓库结构
该项目的仓库里只存储 Soliplay 后端骨架的源代码，但本仓库的 ``Release`` 中已经包含了官方插件，可以直接通过 ``Release`` 直接下载可直接使用的、包含了官方插件与前端的 SoliPlay 应用程序。

出于对本仓库对应项目的稳定性与可靠性的考量，本仓库**不包含**任何 **AI 代码**，也**禁止提交**任何 **AI 代码**到本仓库中。

#### 预定官方插件列表
| 插件名 | 插件类型 | 插件说明 |
| ------ | -------- | --------- |
| SoliPlay 官方故事插件 | 故事核心插件 | 拥有基础的故事构造能力，Token 消耗略小 |
| SoliPlay 官方事实库插件 | 事实库核心插件 | 拥有基础的故事事实管理能力，Token 消耗略小 |
| SoliPlay 官方虚拟历法插件 | 虚拟历法核心插件 | 拥有基础的历法模拟功能 |
| SoliPlay 官方角色管理器 | 角色管理核心插件 | 拥有基础的角色管理功能，玩家可以将角色推送到导演手中。此插件可进一步节省 Token 并增强叙事性。 |
| SoliPlay 官方故事监控插件 | 自由插件 | 在 LLM-故事核心插件 的通路中拦截消息并交由用户审核，用户可以选择重新生成、提出要求修改、放行。|

**点击插件名可以跳转至对应仓库页面！**

（所有官方插件都使用 GNU GPLv3 开源许可证进行开源！）

使用**第三方插件**时，请检查其**安全性**！谨防携带**恶意代码**的插件！以防造成**个人信息泄露、API 泄露**等损失！
